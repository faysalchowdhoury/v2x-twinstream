# Scenarios

`track1..track5.json` are generated by `scripts/make_scenarios.py`. Schema: `start`, `nodes[]` (`t_start_ms`, `t_end_ms`, `narration`, `defender[]`, `gate{t_ms, question, options[]{id,label,effect,next,feedback,score}}` or `terminal`), `data` (case parameters).

Case selection for the two evaluation-derived scenarios was made by a rule fixed in advance, applied to `results/cav_alerts.json` (9-fold group-held-out results):
* track1: first record with `step_offset` where no defence collides but the physics verifier does not.
* track4: the only `ramp_drift` record where Isolation Forest and Random Forest never alert (the follower collides) while the physics verifier prevents the collision. This is a *representative illustration*, not an average; aggregate numbers are in `/api/audit` and the paper figures.
